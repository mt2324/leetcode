## STEP 0
だいぶ前に解いたやつ。
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        occurence = {}
        max_len = 0
        r = 0
        for i in range(len(s)):
            if s[i] in occurence:
                r = max(occurence[s[i]] + 1, r)
            occurence[s[i]] = i
            max_len = max(max_len, i-r + 1)
        return max_len
```

## STEP 1
忘れた頃に解き直すとあれ値の更新どこでするのがいいんだっけ。などの混乱があった。ループのたびに更新しとけばループ出た後にチェックしなくていいんだよな。あとlast_index がleftより左にあるかも確認し忘れたりしていた。
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        left = 0
        max_length = 0
        char_to_last_index = {}
        for right in range(len(s)):
            if s[right] in char_to_last_index and char_to_last_index[s[right]] >= left:
                left = char_to_last_index[s[right]] + 1
            char_to_last_index[s[right]] = right
            max_length = max(max_length, right - left + 1)
        return max_length
```

## STEP 3
練習
```python
from collections import defaultdict


class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        char_to_last_index = defaultdict(lambda: -1)
        left = 0
        max_length = 0
        for right in range(len(s)):
            if left <= char_to_last_index[s[right]]:
                left = char_to_last_index[s[right]] + 1
            char_to_last_index[s[right]] = right
            max_length = max(max_length, right - left + 1)
        return max_length
```
