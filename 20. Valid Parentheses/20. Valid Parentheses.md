## STEP 1
とりあえず書いてみた。
```python
class Solution:
    def isValid(self, s: str) -> bool:
        left = ['(', '{', '[']
        stack = []
        for i in s:
            if i in left:
                stack.append(i)
                continue
            if stack == []:
                return False
            if i == ')':
                if stack.pop() != '(':
                    return False
            if i == '}':
                if stack.pop() != '{':
                    return False
            if i == ']':
                if stack.pop() != '[':
                    return False
        return stack == []
```

## STEP 2
- 辞書で対応で明示すると意図が明確だし、コードの分岐が減る。
- 鍵を開き括弧の方にすると辞書でシンプルに存在確認できてスマート
- pythonの配列の存在内の確認はimplicit falseが一般的らしい。https://google.github.io/styleguide/pyguide.html#2144-decision
- 直接returnで真偽値を書いた方が良い

```python
class Solution:
    def isValid(self, s: str) -> bool:
        open_to_close = {'(': ')', '{': '}', '[': ']'}
        open_brackets = []
        for c in s:
            if c in open_to_close:
                open_brackets.append(c)
                continue
            if open_brackets and open_to_close[open_brackets.pop()] == c:
                continue
            return False
        return not open_brackets        
```
